# E-Commerce React

Aplicación e-commerce desarrollada con React y Vite.

## Tecnologías
- React
- Vite
- React Router DOM
- CSS con variables

## Instalación
```bash
npm install
npm run dev
```

## Componentes
- Header y Footer
- Card reutilizable con props
- Contador con useState
- Formulario con preview en vivo
- Lista de productos con filtros
- To-Do App completa
